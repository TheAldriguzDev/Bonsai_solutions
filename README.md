# Bonsai_solutions

Bonsai solutions has been created to help people to cop limited items.
We are currently providing high quality custom monitors to cookgroups.

## Programming language
Bonsai solutions are written in golang.

## Sitelist:
- Footlocker EU
- Adidas 
- Zalando
- SkateDeluxe
- Vans

## Solver:
We also have our built in solvers, right now we support:
- DataDome

## How to make it works:
You have to add a "proxies" folder in your project and add proxies file, as many as you want.

To start the project, you can follow two possible ways:
- go run main.go
- go build, to create the .exe and run the created file
